Security Token Experiment

Untersuche verschiedene Access-Token anhand ihrer Claims und prognostiziere, ob die API sie akzeptieren wird.

Was wäre ein gültiges Token? Einige Bedingungen ...

1. Der Aussteller

Token müssen von Microsoft Entra ID ausgestellt werden.

2. Der vorgesehene Empfänger

Token müssen für die API ausgestellt sein, die sie aufruft.

3. Die erforderlichen Berechtigungen

Im Token muss die Berechtigung enthalten sein, die die API für den Zugriff benötigt. Diese wurde bei der Registrierung der API in Microsoft Entra ID definiert.

Sind diese Token gültig ?

Untersuche die Claims der verschiedenen Access-Token und entscheide, ob die API sie akzeptieren wird. Klicke auf das Token, und es wird von der API überprüft. Die Ergebnisse werden in der Sicherheitsprüfung angezeigt.Durch Trial and Error erfährst du mehr über die konkreten Werte, die die API erwartet.
